# 3D Models Folder

Place your 3D model files here!

## Supported Formats:
- `.glb` (Recommended - compressed GLTF)
- `.gltf` (GLTF with separate files)
- `.fbx` (Autodesk FBX)
- `.obj` (Wavefront OBJ)

## Where to Get Free 3D Models:
1. **Sketchfab** - https://sketchfab.com/
2. **Poly Pizza** - https://poly.pizza/
3. **TurboSquid** - https://www.turbosquid.com/
4. **CGTrader** - https://www.cgtrader.com/
5. **Ready Player Me** - https://readyplayer.me/ (for avatars)

## How to Use:
1. Download a 3D model (preferably .glb format)
2. Place it in this folder (e.g., `model.glb`)
3. The component will automatically load it!

## Example Files:
- `model.glb` - Your main 3D model
- `avatar.glb` - Character/avatar model
- `logo.glb` - 3D logo
